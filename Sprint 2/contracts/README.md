# Contrats de donnees

- `silver.schema.json` definit les enregistrements types, les anomalies et le lineage.
- `gold.schema.json` definit les KPI calcules et leur statut.
- `serving.schema.json` definit le payload consomme par la maquette.
- `kpi_catalog.json` est la source canonique du catalogue K01-K16 et H01-H08.

Les schemas sont des contrats Sprint 2 proposes. Leur adoption de production reste `Pending partner validation`.
