# Reports and presentations

- `audit/` contient les rapports techniques partageables et les audits internes ignores.
- `progress/` contient le generateur du rapport de progression ; les sorties DOCX/PDF sont ignorees.
- `presentations/` contient les PowerPoint locaux ; les PPTX et sources liees aux pieces jointes restent ignores.

Aucun livrable binaire ne doit etre pousse sans validation explicite de sa classification et du depot cible.
