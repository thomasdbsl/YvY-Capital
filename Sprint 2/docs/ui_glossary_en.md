# Sprint 2 Dashboard English Glossary

This glossary is the translation baseline for the Sprint 2 Funds Manager prototype. Product names, fund aliases, KPI identifiers, run identifiers, and data-layer names remain unchanged.

| Source term | Approved English term | Usage note |
|---|---|---|
| Vue generale | Overview | Main executive dashboard |
| Direction | Executive | User journey and navigation group |
| Fonds | Fund / Funds | Singular for selectors; plural for pages and tables |
| Encours | Assets under management (AUM) | Use AUM in compact cards |
| Valeur de part | NAV per share | Financial reporting terminology |
| Donnees d'exemple | Sample data | Explicitly synthetic values |
| Donnees a jour | Current data | Freshness state, not market-real-time data |
| En retard | Late | Freshness threshold exceeded |
| A valider | Pending validation | Requires a partner or governance decision |
| Qualite des donnees | Data quality | Controls, anomalies, and quarantine |
| Controle | Control / check | Control for governed rules; check for user actions |
| Quarantaine | Quarantine | Isolation of invalid records |
| Rapprochement | Reconciliation | Comparison of positions, cash, provisions, and NAV |
| Pairs | Peers | External benchmark universe |
| Parcours | Journey | Role-based user flow |
| Fraicheur | Freshness | Source recency status |
| Lineage | Lineage | Retained technical governance term |
| Run | Run | Retained technical processing term |
| Serving / Silver / Gold | Serving / Silver / Gold | Retained architecture layer names |
