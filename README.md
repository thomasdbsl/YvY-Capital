# Funds Manager

Funds Manager is a data governance and decision-support project for fund monitoring. Sprint 2 provides a reproducible pipeline based on synthetic fixtures, a local MAMP MySQL database, a read-only PHP API, data contracts, and an interactive dashboard. It is not a production application.

## Repository security

The `origin` remote points to `thomasdbsl/YvY-Capital`. Its GitHub visibility was confirmed as **public on August 23, 2026**. No push should be performed unless the repository is private or these contents have been explicitly authorized.

The following items must remain strictly local and are ignored by Git:

- raw YvY data and portfolio exports;
- private CNPJ, ISIN, and internal identifiers;
- `data_YvY.zip` and other data archives;
- contractual or internal documents in `docs/`;
- unauthorized binary reports, presentations, and screenshots;
- pipeline outputs, caches, and test artifacts.

See [`Sprint 2/docs/security_incident_response.md`](Sprint%202/docs/security_incident_response.md) for the containment context.

## Quick start

Prerequisites: MAMP with Apache/MySQL, Python 3.12, Node.js 20+, and installed npm dependencies. First follow [`MAMP_MYSQL_SETUP.md`](MAMP_MYSQL_SETUP.md) to create and configure the local fictional database.

```powershell
npm install
npm run build
npm start
```

Then open `http://127.0.0.1:4173/src/app/`.

The dashboard loads its data through `MAMP MySQL -> PHP API -> dashboard`. JSON files generated by the pipeline are used only as test fixtures and parity evidence; the browser no longer reads them at runtime.
